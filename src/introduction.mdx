# Tapas UI

Copy-paste landing-page sections for Next.js and shadcn/ui. Every section here is the same file that
`npx shadcn@latest add https://tapas-ui.vercel.app/r/<name>.json` puts in your project.

- **Light and dark:** switch with the theme button in the toolbar. Sections read your shadcn tokens.
- **Accessibility:** open the Accessibility panel on any story to see the axe results.
- **Docs and install commands:** [tapas-ui.vercel.app/docs](https://tapas-ui.vercel.app/docs).
